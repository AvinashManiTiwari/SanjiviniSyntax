# 🌱 SanjiviniSyntax – Web-Based E-Learning Platform

🌐 Project Website: (https://avinashmanitiwari.github.io/SanjiviniSyntax/)

## 📌 About the Project

**SanjiviniSyntax** is a web-based e-learning platform developed to help students learn programming and improve their technical skills through organized learning resources.

The platform brings together programming courses, study notes, video tutorials, quizzes, and other educational resources in one place. Its responsive interface provides a smooth learning experience across desktop, tablet, and mobile devices.

The project focuses on making online education simple, accessible, and engaging through an intuitive user interface and interactive features.

## ✨ Key Features

- 🏠 **Home Page** – An engaging landing page with an overview of the platform.
- 📚 **Courses Section** – Explore programming courses and learning resources.
- 📝 **Study Notes** – Access educational notes for learning and revision.
- 🎥 **Video Tutorials** – Learn concepts through video-based resources.
- 🧠 **Interactive Quizzes** – Practice concepts and test your knowledge.
- 🔐 **Login & Registration** – User interface for account access and registration.
- 🔎 **Search Functionality** – Find relevant courses and learning materials.
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile screens.
- 📩 **Contact Section** – A way for users to reach out with questions or feedback.
- ❓ **FAQ Section** – Answers to frequently asked questions.
- 🔒 **Privacy Policy & Terms** – Dedicated pages for website policies.
- 💾 **Local Storage** – Stores supported user data locally in the browser.
- 👁️ **Password Visibility Toggle** – Show or hide password input while typing.
- 📄 **Error Page** – A dedicated 404 page for unavailable routes or content.
